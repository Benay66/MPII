# MPII Human Pose Estimation

## Description

This project implements a deep learning solution for **Multi-Person Pose Estimation** using the MPII Human Pose Dataset. The goal is to detect 16 anatomical keypoints (joints) per person in images containing one or multiple individuals.

Developed as part of the Neural Networks and Machine Learning course during the Bachelor's Degree in Artificial Intelligence at UPV/EHU.

## Key Objectives
- Accurate detection of body keypoints in complex scenes
- Handling of occlusions and multiple people
- Evaluation using standard metrics: PCK (Percentage of Correct Keypoints) and PCKh

## Dataset
- **MPII Human Pose Dataset** (28,000+ annotated images)
- 16 keypoints per person
- Includes train, validation and test splits
- Images stored in `scripts/dataset/images/`
